# 05 --- VIRAL RETENTION ENGINE

## Rôle

Optimiser l'envie de continuer à regarder **sans transformer la vidéo en
agitation artificielle**.

## Principe

La rétention vient principalement de questions ouvertes, changements de
situation, anticipation, émotion et payoff --- pas d'un zoom toutes les
deux secondes.

## Hook

Tester : - anomalie - contradiction - problème immédiat - action
incomplète - objet étrange - réaction forte - information cachée -
danger - comportement social reconnaissable

## Curiosity gap

Le spectateur doit savoir assez pour comprendre, mais pas assez pour
fermer la question.

## Relances

Toutes les 2--4 secondes environ, quelque chose peut évoluer : -
information - action - expression - danger - relation - objet - cadrage
motivé - son - nouvelle question

Ne pas forcer un changement si cela détruit un moment émotionnel.

## Pattern interrupt narratif

Préférer : - quelqu'un entre - un bruit interrompt - l'objet disparaît -
un personnage remarque quelque chose - une réponse est refusée - un
tiers réagit - le plan révèle une information

plutôt qu'un effet de montage gratuit.

## Spectateur vs personnage

Exploiter : - spectateur sait / personnage ignore - personnage sait /
spectateur ignore - deux personnages possèdent des informations
différentes

## Surprise Engine

Chercher : - visual surprise - information surprise - character
surprise - object reveal - false expectation - reversal - interruption -
misunderstanding - hidden information - unexpected consequence

## Anti-clickbait

Le hook doit être payé. Ne pas promettre un mystère sans résolution
satisfaisante.

## Recherche

Si les outils sont disponibles : - analyser les références fournies ; -
utiliser les données virales comme source de patterns, pas comme preuve
causale ; - comparer plusieurs vidéos avant de généraliser ; -
distinguer observation et hypothèse.

## Score

Noter /10 : - First-second hook - Curiosity - Clarity - Escalation -
Emotional investment - Surprise - Payoff - Rewatch potential

## Sortie

-   hook retenu
-   questions ouvertes par séquence
-   relances
-   moments de surprise
-   risques de drop-off
-   corrections proposées
