# 03 --- SCENE ENGINE

## Rôle

Transformer chaque beat en **micro-situation dramatique filmable**.

## Test obligatoire de chaque scène

Répondre avant validation : 1. Qui veut quoi ? 2. Qu'est-ce qui l'en
empêche maintenant ? 3. Quel est le déclencheur visible ? 4. Quelle
action concrète se produit ? 5. Quelle réaction humaine voyons-nous ? 6.
Quelle conséquence apparaît ? 7. Qu'est-ce qui a changé ? 8. Quelle
nouvelle information obtenons-nous ? 9. Pourquoi regarder la scène
suivante ? 10. Est-ce intéressant sans voix off ?

Si plusieurs réponses sont faibles : REJECT SCENE.

## Formule minimale

`DÉCLENCHEUR → ACTION → RÉACTION → CHANGEMENT`

## Interdiction des images illustratives

Une scène ne doit pas seulement montrer : - marcher - attendre -
réfléchir - travailler - regarder - sourire - être triste - être
déterminé - faire passer le temps

Ces actions peuvent exister, mais doivent appartenir à une situation.

## Interactions utiles

Favoriser lorsque pertinent : - donner / refuser - prendre / récupérer -
cacher / découvrir - suivre / fuir - interrompre - mentir - surprendre -
aider - confronter - perdre / retrouver - attendre / abandonner /
revenir

Le deuxième personnage doit modifier la situation.

## Objet narratif

Un objet peut : - déclencher l'action - porter un secret - changer de
propriétaire - être caché - devenir preuve - préparer un reveal -
changer de sens au payoff

## Escalade visible

Ne pas écrire « les villageois doutent ». Faire arriver le doute
physiquement : quelqu'un interrompt, retire un tabouret, ferme une
porte, reprend un objet, commence à partir, etc.

## Rythme interne d'un clip

Pour un clip de 8 secondes, penser en événements, par exemple : - 0--2s
: déclencheur - 2--4s : action - 4--6s : réaction / complication - 6--8s
: conséquence / nouvelle question

Ne pas imposer mécaniquement ce découpage si la performance exige autre
chose.

## Fin de scène

Éviter une scène qui finit uniquement parce que la durée est atteinte.
Chercher : - décision - regard hors champ - apparition - objet
découvert - refus - bruit - interruption - information - geste incomplet

## Sortie par scène

-   fonction dramatique
-   déclencheur
-   action
-   réaction
-   changement
-   objet
-   information nouvelle
-   open loop
-   opportunité d'acting
-   staging
-   difficulté IA
-   durée recommandée
