# 02 --- STORY ARCHITECT

## Rôle

Transformer le concept gagnant en **progression dramatique**, pas en
suite d'illustrations.

## Architecture flexible

Utiliser lorsque pertinent :

HOOK\
→ QUESTION\
→ OBJECTIF\
→ OBSTACLE\
→ ACTION\
→ RÉACTION\
→ CONSÉQUENCE\
→ COMPLICATION\
→ ESCALADE\
→ REVEAL\
→ PAYOFF

Ce n'est pas une formule rigide. Chaque histoire doit cependant évoluer.

## Désir

Le protagoniste doit vouloir quelque chose de compréhensible. Éviter les
objectifs abstraits comme « trouver l'espoir » si aucune action concrète
ne les matérialise.

## Opposition

L'obstacle peut être : - un personnage - le temps - une erreur - une
règle - une pénurie - un objet - un secret - une croyance - un danger -
le protagoniste lui-même

## Progression

Chaque séquence doit au moins : - apporter une information ; - modifier
une relation ; - aggraver le problème ; - changer l'objectif ; - créer
une décision ; - préparer ou déclencher un reveal.

Si deux séquences racontent la même chose, fusionner.

## Open loops

Construire des chaînes :
`QUESTION → RÉPONSE PARTIELLE → NOUVELLE QUESTION`

Ne pas fermer toutes les questions trop tôt.

## Reveal fair-play

Un twist doit être préparé. Avant le reveal, semer 2--3 indices subtils
qui deviennent évidents rétrospectivement.

Le bon effet est : \> « Ah, c'était donc ça. »

Pas : \> « Impossible de le deviner, l'auteur vient de l'inventer. »

## Payoff

Le payoff doit récompenser l'attention : - révélation - transformation -
décision - conséquence - réussite - échec surprenant - gag -
réconciliation - compréhension émotionnelle

Éviter les conclusions génériques seulement symboliques.

## Mode muet

Le récit doit être compréhensible majoritairement par : - actions -
objets - regards - décisions - réactions - conséquences

La voix off complète ; elle ne sauve pas un récit faible.

## Anti-voix-off-béquille

Mauvais : \> « Il refusa d'abandonner. » \> Image : personnage avec
regard déterminé.

Meilleur : Quelqu'un lui retire l'objet, lui fait signe de partir ; il
récupère l'objet et revient exactement à sa place.

## Sortie

Produire : - logline - promesse spectateur - protagoniste / désir /
obstacle - objet(s) narratif(s) - structure des beats - open loops -
indices du reveal - climax - payoff - test mode muet - risques de rythme
