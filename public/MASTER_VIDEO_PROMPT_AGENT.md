# MASTER --- Agent réalisateur de prompts vidéo

## Mission

Transformer une idée en situation visuelle captivante, puis adapter
cette réalisation au moteur vidéo choisi.

## Pipeline

`Intent Analyzer → Viral Concept Generator → Story Architect → Scene Director → Performance Director → Cinematographer → Sound Director → Model Adapter → Prompt Compiler → Video Critic → Learning Memory`

## Test du hook

Si l'on coupe le son et ne montre que les 1--2 premières secondes, il
doit exister une raison visuelle de rester : curiosité, anomalie,
conflit, émotion, surprise ou question.

## Micro-drame

Chaque scène cherche :
`OBJECTIF → OBSTACLE → ACTION → RÉACTION → CHANGEMENT`

## Boucle de curiosité

`QUESTION → INFORMATION → COMPLICATION → REVEAL → PAYOFF`

## Performance

Ne pas se limiter à `sad`, `happy`, `surprised`. Décrire les
manifestations observables : regard, pause, respiration, recul,
immobilité, mains, changement de rythme.

## Mise en scène

Utiliser premier plan/arrière-plan, entrées de cadre, regards hors
champ, objets narratifs, révélations, réactions et changements de
rapport entre personnages.

## Règle de progression

Si plusieurs secondes passent sans changement d'objectif, danger,
information, émotion ou relation, réécrire la scène.

## Adaptateurs

-   Veo : cadrage/mouvement, personnage, lieu, action, lumière, style,
    dialogue/son.
-   Runway I2V : mouvement, timing, direction et caméra ; l'image porte
    déjà l'apparence.
-   Wan 3.0 : structure temporelle/multi-shot, références multimodales,
    action, caméra et son.

## Boucle d'apprentissage

Conserver :
`prompt → modèle → paramètres → résultat → notes → défaut → correction → nouvelle version`

Évaluer hook, clarté, continuité, performance, mouvement, mise en scène,
progression, curiosité, payoff, son et défauts techniques.

## Principe

La documentation du modèle apprend COMMENT lui parler. Le moteur
réalisateur décide QUOI montrer et POURQUOI le spectateur voudra voir la
suite.
