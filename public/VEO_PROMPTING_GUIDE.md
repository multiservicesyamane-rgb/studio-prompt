# VEO --- Guide pour l'agent

Source étudiée : documentation officielle Google DeepMind Veo.

## Éléments de prompt

-   cadrage et mouvement caméra
-   style
-   lumière
-   description des personnages
-   lieu
-   action
-   dialogue

## Formule agent

`SHOT + CHARACTER + LOCATION + ACTION + CAMERA + LIGHTING + STYLE + DIALOGUE/AUDIO`

## Règle

Décrire une action jouable et un changement visible, pas seulement une
belle image. La caméra doit servir le moment dramatique.

## Contrôle personnage

Conserver les traits réellement utiles à la continuité : apparence,
cheveux, vêtements et accessoires distinctifs.

## Adaptation

Le moteur narratif invente d'abord la scène. L'adaptateur Veo traduit
ensuite cette scène en cadrage, action, performance, caméra, lumière et
son.
